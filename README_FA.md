## 📌 طرح مسئله و انگیزه علمی

در روش‌های مرسوم دینامیک سیالات محاسباتی نظیر حجم محدود (FVM) که مستقیماً معادلات ناویرو-استوکس را حل می‌کنند:
1. **تنگنای معکوس‌سازی ماتریس پواسون فشار:** حل معادله پواسون در هر گام زمانی نیازمند محاسبات سنگین جبر خطی و ارتباط سراسری بین نودهای مش است که مانع موازی‌سازی مقیاس‌پذیر می‌شود.
2. **برتری روش مزوسکوپیک LBM:** در روش بولتزمان شبکه‌ای، سیال به صورت توابع توزیع آماری ذرات فرضی مدل‌سازی می‌شود که روی یک شبکه دکارتی حرکت (Streaming) کرده و به صورت کاملاً محلی با یکدیگر برخورد (Collision) می‌کنند:
   - **بدون نیاز به معکوس‌سازی ماتریس:** تمام محاسبات ناوبری و برخورد محلی هستند.
   - **سرعت پردازش فوق‌العاده:** ثبت میلیون‌ها به‌روزرسانی شبکه در ثانیه (MLUPS).
   - **محاسبه دقیق نیروها با تبادل ممانتم:** تعیین نیروهای درگ و لیفت وارده به بدنه بدون نیاز به انتگرال‌گیری عددی فشار روی سطوح منحنی.

## ✨ قابلیت‌های کلیدی

- 🌪️ **مدل برخورد شبکه D2Q9 BGK:** مدل زمان آرامش منفرد که رفتار جریان تراکم‌ناپذیر نیوتنی را با دقت بالا بازسازی می‌کند.
- 🎯 **ریزش گردابه‌ای فون‌کارمان:** شبیه‌سازی ناپایداری لایه مرزی و ریزش گردابه‌های متناوب ساعت‌گرد و پادساعت‌گرد در رینولدزهای $Re \approx 100-250$.
- 🛩️ **تولیدکننده ایرفویل‌های ناکا (`src/airfoil.rs`):** تولید خودکار مرزهای غوطه‌ور برای پروفیل‌های استاندارد NACA 0012 یا NACA 2412 در زوایای حمله ($\alpha$) مختلف.
- ⚖️ **تخمین نیروهای آیرودینامیکی با تبادل ممانتم:** محاسبه نیروهای عمودی و افقی با ارزیابی ممانتم ذرات منعکس‌شده از دیواره‌های مرزی.
- 🌡️ **انتقال حرارت جابجایی دوجمعیتی (`src/thermal.rs`):** توسعه TLBM برای شبیه‌سازی جابجایی حرارتی طبیعی ریلی-بنارد.

## 🏗️ پایپ‌لاین محاسباتی LBM

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   تعریف دامنه حل و شرایط اولیه شبکه                     │
│               شبکه دوبعدی D2Q9: N_x × N_y گره شبکه دکارتی              │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│                      گام برخورد محلی ذرات (Collision)                  │
│          f_i^*(x, t) = f_i(x, t) - (1 / τ) * (f_i(x, t) - f_i^(eq))    │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│                     گام انتقال فضایی ذرات (Streaming)                  │
│                    f_i(x + c_i * Δt, t + Δt) = f_i^*(x, t)             │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│             اعمال شرایط مرزی پرش بازگشتی (Bounce-Back) و تبادل ممانتم  │
│             محاسبه بردار نیروهای درگ و لیفت آیرودینامیکی               │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│                 استخراج گشتاورهای ماکروسکوپیک هیدرودینامیکی            │
│               چگالی: ρ = Σ f_i  |  میدان سرعت: u = (1 / ρ) * Σ f_i c_i │
│               میدان تاوایی: ω = (∂u_y / ∂x) - (∂u_x / ∂y)              │
└────────────────────────────────────────────────────────────────────────┘
```

## 📐 فرمولاسیون ریاضی بولتزمان شبکه‌ای

### بردار سرعت‌های گسسته و توزیع تعادلی
در شبکه D2Q9 با سرعت‌های ۹گانه $\mathbf{c}_i$ و وزن‌های شبکه‌ای $w_i$:

$$f_i^{(eq)}(\rho, \mathbf{u}) = w_i \rho \left[ 1 + \frac{\mathbf{c}_i \cdot \mathbf{u}}{c_s^2} + \frac{(\mathbf{c}_i \cdot \mathbf{u})^2}{2 c_s^4} - \frac{\mathbf{u} \cdot \mathbf{u}}{2 c_s^2} \right]$$

سرعت صوت در شبکه $c_s = 1 / \sqrt{3}$ است.

### معادله حاکم بولتزمان شبکه‌ای با عملگر BGK
$$f_i(\mathbf{x} + \mathbf{c}_i \Delta t, t + \Delta t) - f_i(\mathbf{x}, t) = -\frac{1}{\tau} \left[ f_i(\mathbf{x}, t) - f_i^{(eq)}(\mathbf{x}, t) \right]$$

لزجت سینماتیکی سیال با زمان آرامش $\tau$ ارتباط مستقیم دارد:
$$\nu = c_s^2 \left( \tau - \frac{1}{2} \right) \Delta t$$

## 🚀 راهنمای نصب و اجرای سریع

```bash
# کلون مخزن
git clone https://github.com/ArdavanGhal-Eh/lattice-boltzmann-cfd-rust.git
cd lattice-boltzmann-cfd-rust

# کامپایل بهینه با کارایی بالا
cargo build --release

# اجرای شبیه‌سازی
cargo run --release

# اجرای اسکریپت مصورسازی کانتور گردابه‌ها
cd python_visualizer
pip install -r requirements.txt
python plot_vortex_street.py
```
